# RiskManager

保育園向けヒヤリハット事案管理デスクトップアプリケーション。

## 概要

保育園内で発生したヒヤリハット（園児のけがや事故）を記録・管理・分析するツールです。
先生たちが事故の傾向を把握し、日常業務の安全改善につなげることを目的としています。

> 詳細な仕様は [要件定義書](docs/requirements.md) を参照してください。

---

## 主な機能

### Phase 1（MVP）

| 機能 | 説明 | 状態 |
|------|------|------|
| パスワード認証 | 起動時のパスワードロック・変更機能 | 完了 |
| ヒヤリハット報告入力 | 発生日時・場所・クラス・園児名・けがの種類・事故内容の記録。クラス・けがの種類はフリーワード追加可。園児名はオートコンプリート対応。タブ切り替えでも入力内容を保持。一括クリアボタン付き | 完了 |
| マスタ管理 | クラス・けがの種類・場所の追加・削除 | 完了 |
| 報告一覧・検索 | 登録済み報告の一覧表示・絞り込みフィルタ | 完了 |

### Phase 2

| 機能 | 説明 | 状態 |
|------|------|------|
| 集計ダッシュボード | 時間帯別（15分刻み）・けが種類別・場所別のグラフ表示 + 期間フィルタ | 作業中 |
| PDFレポート出力 | 集計データをPDFファイルとして出力 | 未着手 |

## 開発環境のセットアップ

```bash
npm install
npm run dev
```

### 注意事項

- `better-sqlite3` ではなく `sql.js`（WASM版）を採用しています。Python / Visual Studio Build Tools のインストールは不要です。
- Windows環境で開発する場合、PowerShellのセッション変数 `ELECTRON_RUN_AS_NODE` が残留するとアプリが起動しない場合があります。`dev` スクリプトに対策済みです。
