# RiskManager

保育園向けヒヤリハット事案管理デスクトップアプリケーション。

## 概要

保育園内で発生したヒヤリハット（園児のけがや事故）を記録・管理・分析するツールです。
先生たちが事故の傾向を把握し、日常業務の安全改善につなげることを目的としています。

## 主な機能

- ヒヤリハット報告の入力・一覧表示
- クラス・けがの種類のマスタ管理
- 時間帯別・けが種類別・場所別の集計ダッシュボード
- PDFレポート出力
- パスワード認証によるアクセス制限

## 技術スタック

- Electron
- React + TypeScript
- SQLite (better-sqlite3)
- TailwindCSS

## 開発環境のセットアップ

```bash
npm install
npm run dev
```
