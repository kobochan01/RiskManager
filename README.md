# RiskManager

![Version](https://img.shields.io/badge/version-1.1.0-blue)
![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11%20%7C%20macOS-lightgrey)
![Offline](https://img.shields.io/badge/動作-オフライン-green)

保育園向けヒヤリハット事案管理デスクトップアプリケーション。

---

## 開発に至った経緯

保育園では、日々の事故やヒヤリハット（園児のけがや事故につながりかねない出来事）を紙の記録用紙や口頭で管理していることが多く、以下の課題がありました。

- **傾向把握が困難**: 時間帯・場所・けがの種類ごとに集計しづらい
- **再発防止策が立てにくい**: データが散在していて分析できない
- **記録の継続が大変**: 手書きの転記作業に手間がかかる

これらの課題を解消し、蓄積したデータをグラフや PDF レポートとして活用することで、先生たちが安全改善につなげられるツールを目指して開発しました。

---

## アプリ概要

| 項目 | 内容 |
|------|------|
| 対象ユーザー | 保育園の先生・管理者 |
| 動作環境 | Windows 10 / 11 64bit、macOS 12 以降 |
| ネットワーク | インターネット接続不要（完全オフライン動作） |
| データ保存先 | Windows: `%APPDATA%\risk-manager\` / macOS: `~/Library/Application Support/risk-manager/` |

### 主な機能

- **報告入力**: ヒヤリハット / インシデント / アクシデントを種別ごとに記録
- **マスタ管理**: 場所・クラス・けがの種類・園児名を自由に追加・編集・削除
- **報告一覧**: 種別・日付範囲・フリーワードで絞り込み。編集・削除に対応
- **集計ダッシュボード**: 時間帯別・けが種類別・場所別のグラフを種別フィルターで確認
- **PDF レポート出力**: 種別ごとの事案一覧と集計グラフをまとめて PDF 保存

## インストール

[GitHub Releases](https://github.com/kobochan01/RiskManager/releases) から最新版をダウンロードしてください。

### Windows

1. `RiskManager.Setup.1.1.0.exe` をダウンロード
2. ダウンロードした exe ファイルをダブルクリックして実行
3. インストールが完了するとデスクトップにショートカットが作成されます

### macOS

1. `RiskManager-1.1.0-arm64.dmg` をダウンロード
2. DMG を開き、RiskManager アイコンを「アプリケーション」フォルダへドラッグ
3. 初回起動時に「開発元を確認できない」と表示された場合は、**右クリック →「開く」→「開く」** をクリック

## 操作説明

### 報告入力

画面左のナビゲーションから **「報告入力」** を選択します。

1. **種別** を選択（ヒヤリハット / インシデント / アクシデント）
2. **発生日時** を入力（日付 + 時・分をセレクトで選択、07:00〜18:59）
3. **場所・クラス・園児名・けがの種類** を選択
4. **事故内容** にテキストで状況を記入
5. **「登録」** ボタンをクリックして保存

「クリア」ボタンで入力内容をリセットできます。

---

### マスタ管理

画面左のナビゲーションから **「マスタ管理」** を選択します。

タブ切り替えで **場所 / クラス / けがの種類 / 園児名** を管理できます。

- **追加**: テキストボックスに名前を入力して「追加」ボタンをクリック
- **編集**: 各行の編集ボタンをクリックして名前を変更
- **削除**: 各行の削除ボタンをクリック（確認ダイアログが表示されます）

---

### 報告一覧

画面左のナビゲーションから **「報告一覧」** を選択します。

登録済みの報告を一覧表示します。

- **絞り込み**: 種別・日付範囲・フリーワード（場所・クラス・事故内容など）でフィルタリング
- **編集**: 行をクリックするか編集ボタンをクリックしてモーダルで編集
- **削除**: 削除ボタンをクリック（確認ダイアログが表示されます）

---

### 集計ダッシュボード

画面左のナビゲーションから **「ダッシュボード」** を選択します。

1. **期間** を選択（今月 / 先月 / 今年度 / 先年度）
2. **種別** を選択（全て / ヒヤリハット / インシデント / アクシデント）
3. グラフが自動更新されます（時間帯別・けが種類別・場所別）
4. **「PDF 出力」** ボタンで種別ごとの事案一覧と集計グラフを PDF として保存

## 開発者向けセットアップ

### 前提条件

- Node.js 20 以上
- Windows 環境を推奨（`npm run dev` スクリプトが cmd 構文を使用。macOS では `npx electron-vite dev` で代替可能）

### 起動手順

```bash
npm install
npm run dev
```

> PowerShell から直接 `npm run dev` を実行するとメモ帳が開く場合があります。
> 詳細は [CLAUDE.md](CLAUDE.md) の「アプリの起動」セクションを参照してください。

### テスト・ビルド

```bash
npm test                       # テスト実行（Vitest）
npm run build                  # プロダクションビルド
npx electron-builder --win     # Windows インストーラー生成（dist/ に出力）
npx electron-builder --mac     # macOS DMG 生成（dist/ に出力、Mac 環境のみ）
```

### テスト用シードデータ

開発・動作確認用に 100 件のサンプルデータを投入できます。

```bash
node scripts/seed.cjs
```

> **注意**: 実行すると既存の `incidents` テーブルが全件削除されてからシードデータが挿入されます。本番データのある環境では実行しないでください。
