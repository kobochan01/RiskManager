## 1. プロジェクト概要

### 1.1 目的

保育園内で発生したヒヤリハット（園児のけがや事故）を記録・管理・分析し、先生たちが事故の傾向を把握して日常業務の安全改善につなげることを目的とする。

### 1.2 背景・課題

- 現状、ヒヤリハット事案を紙や口頭で管理しており、傾向の把握が困難
- 時間帯・場所・けがの種類ごとの集計ができず、再発防止策を立てにくい
- 個人情報（園児名）を含むため、アクセス制限が必要

### 1.3 対象ユーザー

| ユーザー | 役割 |
|---------|------|
| 保育園の先生 | ヒヤリハット報告の入力・閲覧・分析 |
| 園の管理者 | 同上（権限差異なし。単一ユーザー想定） |

### 1.4 利用環境

- **プラットフォーム**: Windows デスクトップアプリ
- **ネットワーク**: オフライン動作（インターネット接続不要）
- **インストール形態**: Windows NSIS インストーラー（.exe）

## 2. 用語定義

| 用語 | 定義 |
|------|------|
| ヒヤリハット | 重大な事故には至らなかったが、ヒヤリとしたり、ハッとした出来事 |
| インシデント | システム内でのヒヤリハット報告データの呼称（`incidents` テーブル） |
| マスタ | クラス・けがの種類・場所など、選択肢として一元管理する共通データ |
| Phase 1 / MVP | 最小限の機能で実用可能な最初のリリース |

## 4. 非機能要件

| 区分 | 要件 |
|------|------|
| 動作環境 | Windows 10 / 11（64bit） |
| オフライン動作 | インターネット接続不要で全機能が動作すること |
| データ保存先 | ローカルファイルシステム（`%APPDATA%/riskmanager/db.sqlite`） |
| セキュリティ | パスワードは scrypt でハッシュ化して保存する。平文保存は禁止 |
| パフォーマンス | インシデント 1,000 件以下での一覧表示・絞り込み操作の応答が 1 秒以内であること |
| 配布形式 | Windows NSIS インストーラー（.exe）として配布する |
| バックアップ | ユーザー自身による DB ファイルのコピーで対応（自動バックアップはスコープ外） |
| 言語 | UI は日本語のみ |

## 6. UI/UX 要件

### 6.1 画面構成

```
┌─────────────────────────────────────────────────────┐
│  RiskManager                       [パスワード変更]  │ ← ヘッダー
├─────────────────────────────────────────────────────┤
│  [報告入力]  [報告一覧]  [マスタ管理]  [ダッシュボード] │ ← メインタブ
├─────────────────────────────────────────────────────┤
│                                                       │
│  各タブのコンテンツ                                   │
│                                                       │
└─────────────────────────────────────────────────────┘
```

### 6.2 画面一覧

| 画面名 | フェーズ | 説明 |
|--------|---------|------|
| ログイン画面 | Phase 1 | 起動時のパスワード入力（初回は設定画面） |
| 報告入力タブ | Phase 1 | ヒヤリハット報告の入力フォーム |
| 報告一覧タブ | Phase 1 | 登録済み報告の一覧・絞り込み・削除 |
| マスタ管理タブ | Phase 1 | クラス・けが種類・場所の追加・削除 |
| ダッシュボードタブ | Phase 2 | 集計グラフとPDF出力 |
| パスワード変更ダイアログ | Phase 1 | ヘッダーから呼び出すモーダル |

### 6.3 共通UI要件

| # | 要件 |
|---|------|
| UI-1 | ウィンドウの最小サイズは 1280×800 とする |
| UI-2 | 入力フォームは Enterキーでの送信・追加操作に対応する |
| UI-3 | 破壊的操作（削除等）は確認ダイアログを必ず表示する |
| UI-4 | 処理結果（成功・エラー）はインラインメッセージで通知する |

## 8. スコープ外（明示的除外）

以下の機能は本プロジェクトの対象外とする。

- クラウド同期・複数端末でのデータ共有
- ユーザー・ロール権限管理（複数アカウント）
- モバイルアプリ・Web ブラウザ対応
- 自動バックアップ・自動アップデート
- メール通知・プッシュ通知
- 帳票の印刷プレビュー（PDFのみ対応）
